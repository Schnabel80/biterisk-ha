# BiteRisk

Home Assistant integration that estimates the **mosquito bite risk**
(low / medium / high) from your existing weather sensors.

## Installation (HACS)
1. HACS → Integrations → ⋮ → Custom repositories
2. Add `https://github.com/Schnabel80/biterisk-ha`, category *Integration*
3. Install **BiteRisk**, restart Home Assistant
4. Settings → Devices & Services → Add Integration → **BiteRisk**

## Removal
Settings → Devices & Services → BiteRisk → ⋮ → Delete.
